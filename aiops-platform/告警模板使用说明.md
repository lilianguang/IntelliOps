# AIOPS 告警模板自定义使用说明

## 一、功能概述

AIOPS 平台支持在「规则管理」中对告警消息进行自定义。通过 `{变量名}` 的方式，可以将规则信息、CMDB 资产信息、日志字段动态插入到告警消息中。

告警模板支持所有告警渠道：钉钉、邮件、Webhook。

---

## 二、入口位置

1. 登录 AIOPS 平台
2. 左侧菜单：**配置中心 → 规则管理**
3. 新增或编辑一条规则
4. 在「动作配置」区域：
   - 勾选 **「触发告警」**
   - 将 **「告警模板」** 开关切换为 **「自定义」**
   - 在文本框中输入模板内容
5. 点击 **保存**

> 如不开启自定义，系统将按规则类型自动使用内置默认模板。

---

## 三、模板语法

采用 Python `string.Formatter` 格式，使用大括号包裹变量名：

```markdown
**[{rule_name}] 告警**
> 告警级别：{risk_level}

- 设备名称：{device_name}
- 设备IP：{device_ip}
- 区域：{region}
```

- 变量缺失时不会报错，会自动替换为空字符串
- 支持 Markdown 格式（标题、表格、列表、代码块等）
- 日志字段均可作为变量使用

---

## 四、可用变量清单

### 4.1 规则固定变量

| 变量名 | 说明 |
|--------|------|
| `{rule_name}` | 规则名称 |
| `{risk_level}` | 风险等级（低/中/高/紧急） |
| `{threshold}` | 阈值数值（仅指标阈值规则） |

### 4.2 CMDB 资产变量（按设备 IP 自动查询）

| 变量名 | 说明 |
|--------|------|
| `{device_name}` | 设备名称 |
| `{region}` | 区域 |
| `{datacenter}` | 机房信息 |
| `{owner}` | 负责人 |
| `{asset_type}` | 资产类型 |
| `{organization}` | 组织归属 |

> CMDB 查询使用的 IP 字段优先级：`device_ip` > `ip` > `hostname` > `client` > `instance` > `host`

### 4.3 日志字段变量

| 变量名 | 说明 |
|--------|------|
| `{log_type}` | 日志类型 |
| `{hostname}` | 主机名 |
| `{topic}` | 日志 topic |
| `{domain}` | 域名 |
| `{request}` | 请求接口 |
| `{status}` | HTTP 状态码 |
| `{responsetime}` | 响应时间 |
| `{client}` | 客户端 IP |
| `{method}` | 请求方法 |
| `{device_ip}` | 设备 IP |
| `{user}` | 操作用户 |
| `{src_ip}` | 来源 IP |
| `{command}` | 执行命令 |
| `{message}` | 日志消息 |
| `{severity}` | 日志级别 |
| `{module}` | 模块 |
| `{metric_name}` | 指标名 |
| `{metric_value}` | 指标当前值 |
| `{instance}` | 实例 |
| `{job}` | 任务名 |

> 日志字段取决于具体数据源，只要日志里有的字段都可以作为变量使用。

---

## 五、区域来源说明

`{region}` 变量的取值逻辑如下：

1. **优先从 CMDB 查询**：根据日志中的 IP 查询 `cmdb_assets` 表，返回资产的 `region` 字段
2. **CMDB 无区域时，按 topic 映射**：
   - `nginx-access-log-8ov` → **政务外网**
   - `nginx-access-log-int` → **互联网**
3. 若两者都没有，则 `{region}` 为空

## 八、指标阈值告警模板参考（含网络设备 Prometheus 监控）

**适用规则类型**：指标阈值告警（含「网络设备-监控」这类多条件 Prometheus 监控规则）

```markdown
📊 **[{rule_name}] 指标阈值告警**

> 告警级别：{risk_level}

**指标信息**
- 实例：{instance}
- 任务：{job}
- 指标名：{metric_name}
- 当前值：{metric_value}
- 触发阈值：{operator} {threshold}

**关联设备**
- 设备名称：{device_name}
- 设备IP：{device_ip}
- 所属区域：{region}
- 负责人：{owner}
```

### 8.1 多条件规则的阈值变量说明

「网络设备-监控」等规则可在一条规则里配置**多个指标条件**（如接口光衰、各方向流量、错误包等），示例：

```json
{
  "logic": "OR",
  "threshold": { "count": 2, "window_minutes": 20 },
  "conditions": [
    { "metric": "memory_usage", "operator": ">", "value": 70 },
    { "metric": "接口光衰", "operator": "<", "value": -15 },
    { "metric": "政务外网接口入方向流量", "operator": ">=", "value": 1000 }
  ]
}
```

此时模板中的 `{metric_name}`、`{metric_value}` 为**本次实际触发的指标**，而 `{threshold}`、`{operator}` 会**自动取该指标对应条件**的阈值与比较符。例如接口光衰触发时，`{operator} {threshold}` 渲染为 `< -15`。

> ⚠️ 注意：配置顶层的 `threshold: {count, window_minutes}` 是**频率去重阈值**（N 分钟内触发 M 次才告警），**不是**指标阈值，不会填入 `{threshold}` 变量。

### 8.2 新增可用变量

| 变量名 | 说明 |
|--------|------|
| `{operator}` | 比较符（`>`/`>=`/`<`/`<=`/`==`/`!=`），多条件时取本次触发指标对应条件 |
| `{threshold}` | 指标阈值，多条件时取本次触发指标对应条件的 value |

## 九、简洁版模板（适合钉钉/微信快速阅读）

```markdown
🚨 [{rule_name}] {risk_level}

**{device_name}** ({device_ip}) | {region}
{message}
```

**效果示例**：

```markdown
🚨 [核心交换机危险命令监控] 高

**出口防火墙** (192.168.37.3) | 政务外网
User admin executed reboot from 10.0.0.5
```

## 十、注意事项

1. **变量区分大小写**：`{device_ip}` 可用，但 `{Device_IP}` 会识别为空
2. **缺失字段不报错**：如果日志中没有某个字段，该变量会显示为空
3. **CMDB 数据准确性**：设备名称和区域依赖 `IT资源管理 → 资产管理` 中的数据，请确保 IP 录入准确
4. **topic 映射规则**：当前仅内置 `nginx-access-log-8ov` 和 `nginx-access-log-int` 两个映射，如需扩展请联系开发团队
5. **渠道兼容性**：钉钉支持 Markdown 完整渲染，邮件为纯文本格式，Webhook 接收 `{"text": "渲染后消息", "msgtype": "markdown"}`

---

## 十一、模板优先级

当规则触发时，系统按以下顺序选择模板：

1. **用户自定义模板**（`action_config.alert_template`）
2. **规则类型默认模板**（系统内置）
3. **通用兜底模板**

因此只要开启了「自定义」并填写了内容，就会优先使用你的模板。
