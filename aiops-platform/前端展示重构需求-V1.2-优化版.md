# 前端展示页面重构需求（优化版 V1.2）

> 原始需求：`前端展示重构需求-V1.1.md`  
> 优化方向：补充实现细节、明确数据源与接口依赖、拆分优先级、标注待确认事项。

---

## 一、重构目标

1. 统一平台品牌视觉：顶部 Logo + 站点名称可配置。
2. 左侧导航从「功能堆砌」升级为「场景化分组」：
   - 以 **AI 运营中心** 为首页入口
   - 以 **AI 智能中心** 聚合所有 AI 能力
   - 以 **资源中心** 聚合所有资源管理
   - 以 **事件中心** 提供事件全生命周期入口
3. AI 运营中心首页提供运营概览，支持快捷跳转。
4. 新增「系统管理」模块，集中管理站点视觉配置。

---

## 二、重构范围与影响面

| 范围 | 说明 |
|------|------|
| 前端菜单 | `MainLayout.vue` 菜单结构重构 |
| 前端首页 | 新增 `AIOpsCenterView.vue`（原 DashboardView 升级或替换） |
| 前端路由 | `router/index.js` 增加/调整路由 |
| 前端样式 | 站点 Logo、主题色/背景色配置能力 |
| 后端接口 | 部分模块需要新增统计/分析类接口 |
| 数据库 | 新增 `site_settings` 或扩展 `configs` 表存储站点配置 |

---

## 三、左侧导航重构（详细）

### 3.1 顶部 Logo 区

**需求**：在左上角「AIOPS 运维平台」文字左侧增加一个云图标 Logo。

**细化建议**：
- 默认使用 Element Plus 的 `<Cloudy />` 图标或自定义 SVG。
- 图标与文字间距 `8px`。
- 收起侧边栏时，仅显示图标/首字母。

**建议升级为可配置**：站点 Logo 和名称由后端 `site_settings` 接口提供，便于不同客户部署时替换。

## 五、事件中心二级菜单补充说明

### 5.1 实时事件

- 默认筛选最近 24 小时
- 页面：`/events/realtime`
- 复用现有 EventCenterView，默认时间范围 `now-24h`

### 5.2 历史事件

- 支持时间快捷选择：最近 3 天 / 7 天 / 30 天 / 自定义
- 页面：`/events/history`

- 调用大模型对**单条**选中事件进行推理分析

- 页面：`/events/analysis?id={eventId}`
- **需要后端接口**：`POST /api/events/{id}/analyze`（流式响应）

### 5.4 事件统计

- 统计面板：事件分类、趋势图（~~MTTR、MTBF~~ 已确认：不考虑）
- 页面：`/events/statistics`
- **需要后端接口**：`GET /api/events/statistics`
